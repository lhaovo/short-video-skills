# 生产作业

配合 SKILL.md 的七步流程。这份文件管「怎么把一批图高效地做出来，并且不丢不乱」。

---

## 一、读清单时看四件事

| 看什么 | 用来决定 |
|---|---|
| 编号与类型 | 分组，同类一起做 |
| 被哪些段引用 | 排序，引用多的先做 |
| 来源（实拍 / AI / 官方） | 走哪条生产路径 |
| 是否已有 | 已有的直接验收，不重出 |

清单里缺「用途」这一列的，先补上——用途是命名的一半（`PR-01_产品主图_v1`），也决定画幅。

---

## 二、生产顺序：按依赖排，不按列表顺序

```
产品主图 ──┬──→ 产品角度图
           ├──→ 产品细节图
           └──→ 首帧图（与场景合成）

场景全景 ──→ 场景局部 / 光效

人物三视图 ──→ 人物表情 / 手部 / 服装细节
```

规则三条：

1. **锚点先做**，派生照它长
2. **同组连续做**，不要产品做一半去跳场景——换了工具参数再回来，色调就对不上了
3. **首帧最后做**，它依赖产品与场景两边的资产

---

## 三、定级：三个判据

| 判据 | 说明 |
|---|---|
| 被引用次数 | ≥3 段 → 锚点级 |
| 是否承载身份 | 产品本体、主角脸、主场景 → 锚点级 |
| 出错代价 | 错了要牵连重做的，升一级 |

反过来，只出现一次、不影响其他图的，一律按一次性处理。

**默认不要全按锚点做。** 一条 30 秒的片子，锚点级通常只有 2–3 个（产品、主场景、可能一个人物），其余都是派生或一次性。

---

## 四、出候选：什么时候多，什么时候少

| 情况 | 策略 |
|---|---|
| 锚点级 | 4–6 张，同一提示词多跑；挑一张定版 |
| 派生级 | 2–3 张，必须与锚点并排看 |
| 一次性 | 1–2 张，能用就用 |
| 反复出不对 | 别再跑，换变量（见下） |

### 加候选的唯一理由

不是「想更好看」，而是「有明确的不合格项」。比如：

- 这张 logo 糊了 → 加候选
- 这张手多了根指头 → 加候选
- 这张看着不够高级 → **不加**，这是审美偏好，不是缺陷

没有缺陷就不追加，否则会陷入无限重抽。

### 反复出不对时的换变量顺序

```
提示词措辞 → 参考图 → 画幅与构图 → 生成模式 → 换工具
```

一次只换一个。三个一起换，出了好图也不知道为什么好。

## 五、落盘与命名

### 目录

```
04-素材/01-资产图/
```

首帧图放 `04-素材/02-首帧/`，不混在资产图里——首帧是「段」的属性，资产是「片」的属性。

### 命名

```
<编号>_<用途>_v<N>.<ext>
```

| 部分 | 规则 | 例 |
|---|---|---|
| 编号 | 与清单完全一致，大写；状态后缀 A/B 保留 | `PR-01`、`CH-01A` |
| 用途 | 2–8 字，需要更细可用下划线连接 | `产品主图`、`身份锚点`、`丁克大脚丫_身份锚点` |
| 版本 | `v1` 起，递增 | `v3` |
| 扩展名 | 保留原格式，不转来转去 | `.png` / `.jpg` |

对：

```
PR-01_产品主图_v1.png
PR-01_产品主体_侧面_v2.png
SC-01_办公桌面_v1.png
CH-01_女性手部_v1.jpg
```

错：

```
产品图.png              ← 没编号，下游不知道挂哪
PR-01.png               ← 没用途，多角度会互相覆盖
PR-01_产品主图_final.png ← 用了 final，就没有 final2 的余地
PR-01_产品主图_v1 (1).png ← 系统重名后缀，脚本不认
```

**不用 `final`、`new`、`最新`。** 版本号是唯一可靠的东西。

### 不删旧版

选定 `v3` 之后，`v1`、`v2` 留着。理由很实际：成片出来发现 v2 的光更顺，你还能退回去。

## 六、回写清单

每张图落盘后，改三处：

| 改哪 | 改成什么 |
|---|---|
| 状态列 | 已有 / 已有备选 / 待补 |
| 工单的选定版本 | `v3` |
| 备注 | 缺什么、为什么 |

状态只有三种，不要自创第四种。「差不多能用」就是「待补」。

---

## 七、中途换工具怎么办

换模型或换工具时，一致性最容易断。三条：

1. **先拿已定版的锚点重跑一次**，看新工具出的是不是同一个东西
2. 如果差异明显，**锚点不换**，只让新工具做派生，并加大候选数
3. 记录换工具的时间点，写进工单备注——后面出问题好定位

## 八、时间分配的实话

一条 30 秒、4–5 段的片子，资产阶段的真实比例大概是：

| 环节 | 占比 |
|---|---|
| 出候选 | 60% |
| 验收与比对 | 25% |
| 命名落盘与回写 | 5% |
| 补拍 / 补出 | 10% |

**出候选是大头。** 所以第 3 步的定级和第 4 步的候选数必须提前定，否则会在某一张图上花掉半天。

# 验收与比对

图出完了不等于能用。这份文件管「留哪张、打回哪张、为什么」。

---

## 一、七项验收

逐项打勾，不要整体「感觉还行」。

| # | 项 | 看什么 | 不合格的样子 |
|---|---|---|---|
| 1 | **几何** | 形状、比例、接缝位置、部件数量 | 杯身变胖、盖子和杯口对不上、多出一圈凹槽 |
| 2 | **印刷与标识** | logo 字形、文字、刻度、标签位置 | logo 缺笔画、字变乱码、刻度数错 |
| 3 | 颜色 | 主体色、环境色偏、整体色温 | 白杯发灰、白杯发蓝、暖光下变成米黄 |
| 4 | 光位与质感 | 主光方向、反光强度、材质感 | 上一张左光这张右光、金属变成镜面 |
| 5 | 构图与画幅 | 主体占比、留白、安全区 | 主体贴边、竖屏里主体偏到一侧 |
| 6 | 背景与杂净 | 白底是否纯白、有无多余物件 | 白底有投影、背景多出一只手 |
| 7 | 瑕疵与结构 | 手指数量、关节走向、内部结构 | 六根手指、内胆透视错乱、物体悬空 |

### 通过线

| 级别 | 要求 |
|---|---|
| 锚点级 | **7/7，且第 1、2 项必须过** |
| 派生级 | 6/7，第 1、2 项必须过 |
| 一次性 | 5/7 |

**第 1、2 项是硬线。** 几何错、印刷错的图，越往下游越贵——生成视频时每一帧都在放大这个错。

## 二、并排比对（最有效的一招）

单看一张图，人眼会自动补全，看不出差别。放一起才看得出来。

### 做法

1. 把锚点图和待验图**缩到同一尺寸**，左右并排
2. 沿四条线看：

| 线 | 看什么 |
|---|---|
| 轮廓线 | 外轮廓是否重合（形状、比例） |
| 标识线 | logo 的相对位置、大小、朝向 |
| 光位线 | 高光在左还是右，阴影落在哪一侧 |
| 基准线 | 桌面线 / 地平线是否同一高度 |

3. **遮住一半看另一半**：遮住左边看右边，两张是否像同一个物件的同一半
4. **镜像翻转一次**：翻转后如果觉得「明显不对」，说明原图有左右不对称的错（尤其人脸）

### 比对记录

差异写出来，不要只写「有点不一样」：

```
PR-01 vs PR-01_侧面_v2：
- 轮廓：杯口宽约 +3%，肩线略高
- 标识：logo 位置偏高约 2mm，字形一致
- 光位：一致
→ 判定：轮廓超差，打回
```

## 三、打回规则

### 打回不是重写提示词

先定位是哪一类问题，再决定改什么：

| 问题类型 | 先改什么 |
|---|---|
| 构图不对（主体太小、贴边） | 画幅与景别描述 |
| 内容不对（少了个结构、多了个物件） | 主体描述 |
| 质感不对（太亮、太塑料） | 光线与材质描述 |
| 一直变样（同一提示词结果差异大） | 换参考图、固定种子、换模式 |
| 全都对但就是不像 | 参考图优先于文字，先用图锁 |

**一次只改一个变量。** 同时改三处，出了好图也不知道是哪处起的作用，下一张又回到原点。

### 三次规则

同一张图连打回 3 次，停手，换策略：

```
改提示词 → 换参考图 → 换画幅构图 → 换生成模式 → 换工具 → 改实拍
```

不要在同一层反复试第 4 次。

### 不许「先凑合用」

凑合用的图有三个后果：

1. 生成视频时一致性崩，观众一眼看出换了个东西
2. 剪辑时被迫用转场遮，节奏变差
3. 返工时前面所有段都要重出

**宁可在资产阶段多花两小时，不要在成片阶段推倒重来。**

## 四、缺陷图谱

| 缺陷 | 一眼识别 | 根因 | 改法 |
|---|---|---|---|
| 白底不白 | 背景灰、有渐变、有投影 | 没写「纯白无缝背景」，或写了场景词 | 补 `pure white seamless background, no shadow on background` |
| 金属过曝 | 表面大面积死白 | 写了「镜面」「高光」「金属质感」 | 改「哑光、低反光」，光位改漫射 |
| 产品变胖/变瘦 | 与锚点并排看轮廓 | 用了大角度或广角 | 换 45 度正视，或直接以锚点图作参考 |
| 多角度不像同一个 | logo 位置、颜色不一致 | 角度图重写了主体描述 | 主体描述从锚点逐字复制 |
| 表面出现文字 | 有莫名其妙的水印、标签 | 模型自行添加 | 加 `no text, no watermark, no label` |
| 手指数量错 | 数一遍 | 手部特写缺细节约束 | 写「五指完整、关节清晰」，或改成不露全手 |
| 人脸/皮肤发脏 | 放大看有斑驳、油光 | 皮肤高频太密 | 按人物负向段重出，压掉毛孔与油光 |
| 构图总是太满 | 主体顶天立地 | 缺景别词 | 写「主体占画面约三分之一，四周留白」 |
| 风格漂移 | 与上一张质感不同 | 风格词每张重写 | 风格句固定，逐张复用 |

## 五、验收之后

通过之后做三件事，缺一不可：

1. **改名落盘**，按 `<编号>_<用途>_v<N>` 
2. **在工单里写选定版本**，写 `v2` 不写「第二版」
3. **把清单状态改成「已有」或「已有备选」**

写完再做下一张。攒着一起写，最后一定漏。

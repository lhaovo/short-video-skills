# 图像提示词骨架

清单里没写图像提示词时，从这里取骨架填。四类资产，四种写法。

---

## 一、四条通用规则

1. **顺序固定**：画幅 → 景别视角 → 主体外观 → 状态 → 环境 → 光影 → 风格
2. **主体外观每次写全**，不写「同上」——模型没有记忆
3. **风格句固定一句**，全片逐字复用，不每张换说法
4. **负向段放在最后**，只写真正的禁忌，不超过两行

---

## 二、产品白底图（母版）

用于：一致性锚点、后续所有角度图的参照。

```text
[画幅] 9:16 竖版（或 1:1 方图），产品白底图。
[主体] {{产品全称}}，{{形状：圆柱/方形/不规则}}，{{材质：哑光漆面/拉丝金属/磨砂塑料}}，
{{颜色：具体色名}}，{{结构：杯盖浅灰硅胶圈，接缝在底部一圈}}。
[标识] 侧面纵向银色 logo，字形完整；正面有 {{容量标注}}。
[视角] 正面 45 度，产品完整入画，居中，四周留白约 15%。
[光影] 顶部均匀漫射光 + 左右补光，金属低反光，无硬阴影。
[风格] 商业产品摄影，干净克制，纯白无缝背景。
[负向] no text overlay, no watermark, no logo distortion, no reflection artifacts,
no harsh shadow, no props, no hand
```

要点：

- 白底写 `pure white seamless background`，加 `no shadow on background`，否则一定带灰底或投影
- 金属一定写「低反光 / 哑光」，否则高光会吃掉结构
- 45 度是折中角度：正视图太平、斜视图容易变形

## 三、产品在场景中（首帧用）

用于：把产品放进真实使用环境，产出首帧图。

```text
[画幅] 9:16 竖版。
[场景] {{空间整体结构与体量}}。前景 {{}}；中景 {{产品位置}}；远景 {{}}。
[主体] {{与母版完全一致的主体描述，逐字复制}}。
[状态] {{开盖 / 手持 / 放在桌面}}，{{朝向}}。
[光影] {{主光方向与色温}}，产品表面受 {{}} 影响，{{阴影落点}}。
[风格] 写实，{{手机随拍 / 商业广告}}质感，{{色调}}。
[负向] no text, no watermark, no extra products, no distorted logo
```

要点：

- **主体描述必须从母版逐字复制**，这是唯一可靠的一致性手段
- 场景先写空间体量，再写物件；反过来会得到一堆悬浮道具
- 产品在场景里最容易「融化」进背景，加一句「产品边缘清晰，与背景分离」

## 四、场景空镜

```text
[画幅] 9:16。
[空间] {{房间大小、层高、开阔或逼仄}}，{{整体布局}}。
[分层] 前景 {{}}；中景 {{}}；远景 {{}}。
[机位] {{平视 / 略高 / 略低}}，{{焦段感}}。
[光影] {{主光方向与色温}}，{{阴影色调}}，{{空气状态：清晨薄尘 / 雨后湿气}}。
[风格] 写实，{{色调}}，无人物。
[负向] no people, no text, no watermark, no clutter
```

要点：

- 空镜也要写「无人物」，否则会塞一个人进去
- 空气状态是氛围的关键，比堆形容词有用

## 五、人物

### 5.1 三视图（锚点）

```text
Character reference sheet, {{正面 / 侧面 / 背面}} view of {{anchor phrase}}，
full body, neutral standing pose, facing camera straight on,
plain neutral grey background, soft uniform studio light,
clean commercial style, 4K, highly detailed, no text, no logo.

no freckles, no facial spots, neutral relaxed expression, no emotion,
no studio strobe, no softbox hard light, no split lighting, no half-lit face,
skin clean smooth and even-toned, no oily specular highlights, no blotchy redness
```

要点：

- 三张共用同一段 anchor phrase，只改「正面/侧面/背面」
- **中性表情、自然站立、正面平视**——资产图不要有情绪和动作
- 皮肤高频要压掉：这张图要喂视频，毛孔与油光会逐帧变成噪点

### 5.2 手部特写

```text
[画幅] 9:16。
[主体] {{性别}}手部特写，{{年龄感}}，{{袖口描述}}，指甲干净无修饰，五指完整。
[状态] 手停在{{抓握进行到一半}}的状态，拇指压在 {{}} 边缘。
[环境] {{简要场景}}。
[光影] {{主光方向}}，皮肤自然，无油光。
[风格] 写实，{{色调}}。
[负向] no extra fingers, no deformed hand, no text, no watermark,
no oily skin, no blotchy redness
```

要点：

- **必须数手指**。手部是残次率最高的部位
- 写「五指完整、关节清晰」，比写「自然的手」有用

## 六、纯 AI 生成时的三个稳定技巧

| 技巧 | 做法 |
|---|---|
| 锁结构 | 把「有几个部件、接缝在哪、开口朝哪」写死，模型没有发挥空间就不会乱加 |
| 控光线 | 光源方向与色温写死一句，全组复用；光线一换，看起来就是另一个东西 |
| 单一变量 | 一次只改角度或只改光，不同时改两样 |

---

## 七、会让图跑偏的词

| 不要写 | 原因 | 换成 |
|---|---|---|
| 高级感、质感好、有设计感 | 不指向任何可见特征 | 具体材质、工艺、光位 |
| 好看、漂亮、精致 | 主观，每次理解不同 | 比例、对称、边缘清晰 |
| 真实感、电影感（单独写） | 无信息量 | 光源 + 色调 + 质感 |
| 优化一下造型 | 模型会真的改形状 | 不要写，改参考图 |
| 类似某品牌 | 会抄到不该抄的部分 | 描述具体特征 |

---

## 八、一条自检

写完提示词，问自己一句：**这段话，换个人照着拍，能拍出同一张图吗？**

能，就是合格的施工指令。不能，说明还有词是形容词。

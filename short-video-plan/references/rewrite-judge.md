# 已有剧本的判定与改写

配合 SKILL.md 的 Step 2 使用（入口 ②）。输入是一份从别处拆出来的剧本：结构、台词、镜头顺序都齐，但它写的是**别人的事实**。

这份文件解决四件事，顺序不能换：**先问要复刻到什么程度，再判能不能用，再定怎么改，最后查有没有抄。**

---

## 一、先问复刻需求（四件事）

拿到剧本，第一句不是「我帮你改」，而是问清楚这四件。

| # | 问什么 | 为什么必须问 | 用户没给怎么办 |
|---|---|---|---|
| 1 | 复刻目的 | 借结构、借选题、借表达，三种改法完全不同 | 默认「借结构」 |
| 2 | 素材替换 | 产品、人物、场景、案例各换成什么 | 列出来，逐项标「待确认」 |
| 3 | 必须保留 | 哪一段、哪句话、哪个节奏不能动 | 默认全可动 |
| 4 | 必须换掉 | 原片里哪些内容你不想沾 | 默认无 |

### 为什么要问「必须保留」

用户常常嘴上说「全改」，心里有一个非留不可的点——可能是那句开头，可能是那个反转。不问，改到第三稿他才说「这个不能删」，前面全废。

### 输出：一张复刻需求卡

```
原片：
复刻目的：借结构 / 借选题 / 借表达
素材替换：产品 → ___ ｜ 人物 → ___ ｜ 场景 → ___ ｜ 案例 → ___
必须保留：___
必须换掉：___
```

这张卡在门 2 之前给用户看一遍，确认无误再往下走。

### 目的决定强度：三种组合，只有一种允许原样

复刻目的不是标签，它直接限制了强度能选到哪一档。

| 复刻目的 | 含义 | 允许的强度 | 为什么 |
|---|---|---|---|
| **借结构** | 用它的讲法讲我自己的事 | A 或 B | 结构骨架属公共知识，换掉内容后原样复刻与「同结构不同内容」是一回事 |
| **借选题** | 这个题好，我也讲这个题 | **只能 B** | 同一题 + 同结构 + 同表达 = 翻录，A 必然踩红线「顺序照抄且无增量」 |
| **借表达** | 想学它的镜头语言、口播风格 | **只能 B**，且方向锁迁移或反写 | 表达是相似度最高的部分，A 等于连句子一起搬 |

三条推论，问的时候直接用：

- 用户说「借选题」却想选 A → 组合不成立，指出冲突：**同题不同讲法才有意义，同题同讲法是翻录**
- 用户说「借表达」却想选 A → 表达不能原样借，最多借节奏与镜头语言，口播必须全重写
- 用户说「借结构」选 A → 唯一合法的原样组合，但仍要先确认自有或授权

**组合冲突时不迁就。** 先说清为什么冲突，再让用户改一个：改目的，或改强度。默认全部迁就，等于把风险留给用户。

## 二、再定复刻强度（二选一，默认第二种）

需求卡确认后，问这一句：

> 「这条你是想**原样复刻**（只换素材，节奏照搬），还是**保留主线但有改动**？默认走第二种。」

| 选项 | 做什么 | 适用 | 代价 |
|---|---|---|---|
| **A 原样复刻** | 结构、顺序、节奏一比一，只替换素材 | 原片是你自己的内容、你有授权、或只作内部参考 | 风险最高：实质相似，容易被判搬运 |
| **B 保留主线但有改动**（默认） | 保留剧情或论证的主线骨架，关键节点、案例、表达重做 | 绝大多数情况 | 工作量增加，但成品是你自己的 |

### 选 A 之前必须问一句

> 「这条原片是你自己的，还是你有授权？」

三个答案，三种处理：

- 是自有或已授权 → 可以做，但仍要处理原片里的红线表述（功效、证言、绝对化）
- 不确定 → 明确说出风险，建议改走 B
- 不是 → **不建议做**，直接说明原因，然后问要不要按 B 改

技能不提供「改到查不出来」的做法。改动的目的是形成自己的表达，不是绕过判定——平台看的是实质相似，不是字面相似。

### B 的七个改动点

选了 B 就把这七处逐个过，缺一处都不算改够。

| # | 改哪里 | 最少改到什么程度 |
|---|---|---|
| 1 | 案例与数据 | 全部换成自己的，且能复现 |
| 2 | 切入疑问 | 换一个提问角度（为什么会这样 → 为什么我总做错） |
| 3 | 论证 / 剧情顺序 | 至少调换两段顺序，或改变因果链的入口 |
| 4 | 口播表达 | 全部重写，不保留原片金句、口头禅、标志句式 |
| 5 | 视角 | 换讲述人，或换人群（自己 → 同事 / 职场人 → 宝妈） |
| 6 | 增量 | 补一条原片没有的信息、反例或条件 |
| 7 | 结尾 | 落点与结尾动作重写，不沿用原片 CTA |

**改够了的判据**：把两张分镜表并排放。**连续 3 镜以上的功能与画面完全对应，就是没改够。** 这一条比任何文字标准都好用，因为它看的是结果不是意图。

## 三、判定顺序：先看结构，再看事实

顺序不能反。先看事实容易陷入「这个案例我没有，但我可以找一个差不多的」——那正是洗稿的起点。

### 1. 结构能不能独立成立

动作：把原片主题抽掉，只留结构骨架，看它是否还是一个完整的讲法。

```
原片：《为什么你的咖啡出门就凉》
抽掉后：【反常识】→【讲机制】→【给一个动作】
```

抽出来的骨架属于公共知识，可以用。

反过来，如果抽掉主题之后结构就散了，说明这条片子的结构是为那个具体主题长出来的，**不能迁移**——只能借鉴它的开头句式，不能借骨架。

### 2. 事实能不能换成你的

逐段核对，每个案例、数字、经历都要有你的对应物。

| 原片里的东西 | 你能不能换 |
|---|---|
| 一个具体案例（某人某事） | 你有自己的同类经历吗 |
| 一个数字（实测、比例、时长） | 你自己测过吗，能复现吗 |
| 一个行业观察 | 你在现场见过吗 |
| 一个身份（我做这行 X 年） | 你的真实身份支持这句吗 |

换不掉的，**整段删**。不留「差不多」「类似地」——这类词是洗稿最明显的标记，也是最容易被平台判定的地方。

### 3. 有没有独家增量

问一句：这条片子比原片多给了观众什么？

- 更细的机制
- 更具体的条件
- 一个原片没有的反例
- 一个更便宜/更省时的做法

一条都补不上，就只能做「借结构不借结论」——即用它的讲法讲一个它没讲的道理。

## 四、三方向的具体做法

强度定了 B，再从这里选路线。

| 强度 | 可选方向 |
|---|---|
| A 原样复刻 | 锁定「仿写」，且只换素材；其他两个方向不适用 |
| B 保留主线 | 仿写 / 迁移 / 反写，三选一 |

### 仿写

**做法**：结构照搬，内容全换。

```
原：为什么咖啡出门就凉 → 双层内胆 → 换一个装法
你的：为什么饭盒带到公司就凉 → 分层保温结构 → 换一个装法
```

**适用**：同一个赛道、同一个受众，想在最短时间内复制一个已验证的讲法。

**代价**：同质化风险最高。同赛道里可能已经有十条一样的片子，你的差异只剩表达。

**必做**：至少换掉两个维度（切入疑问或举证方式），否则就是翻录。

### 迁移

**做法**：结构不动，换人群或换场景。

| 类型 | 迁移什么 | 例子 |
|---|---|---|
| 科普干货 | 换现象，不换机制 | 原讲「咖啡为什么凉」→ 改讲「汤为什么越热越咸」 |
| 剧情软广 | 换冲突，不换产品 | 原讲「上班来不及吃早饭」→ 改讲「带娃出门来不及吃早饭」 |

**适用**：结构很强但你手上没有原片的素材；或者你想打一个竞争更小的人群。

**代价**：要重新找一整套对应素材，工作量接近重写。迁移不是省力，是省判断。

### 反写

**做法**：反着原片的结论讲。

```
原：双层内胆是最优解
反：双层内胆不是关键，关键是别装满
```

**适用**：你对这件事有不同判断，且有论据。

**代价**：最高。需要三条准备：

1. 一个明确的相反主张（一句话）
2. 至少两个支撑论据（不能只有个人感觉）
3. 一个不冒犯原片观众的表述方式（说「还有另一个角度」，不说「那种说法是错的」）

**红线**：反写必须有论据。没有论据的反写是抬杠，会让评论区变成战场，而不是讨论区。

## 五、洗稿的四条红线

判定时逐条过，命中任一条都必须重写，不接受「改几个词就行」。

| 红线 | 具体表现 |
|---|---|
| 事实照抄 | 数字、案例、经历换了个说法但内容相同 |
| 顺序照抄且无增量 | 段落顺序一模一样，也没多给任何信息 |
| 口头禅照抄 | 原片的标志性句式、金句原样保留 |
| 结构照抄但换了行业 | 换了赛道，骨架和节奏一比一还原，等于把别人的方法搬去另一个领域卖 |

第四条最隐蔽，因为它看起来「换了内容」。判断方法：把两条片子的分镜表并排放，如果每一镜的功能完全对应，就是照抄结构。

**第四条与复刻强度直接相关**：选了 A，第四条基本必中；选了 B 但没做够七个改动点，同样会中。

---

## 六、判定结论怎么写

判定不是内部思考，要写出来给用户看。固定六行：

```
复刻强度：原样 / 保留主线但有改动
需求卡：目的___ ｜ 替换___ ｜ 必留___ ｜ 必换___
结构：可迁移 / 不可迁移（理由一句）
事实：可替换 X 段 / 有 Y 段换不掉（列出哪几段）
增量：我能补上 ___ / 补不上
→ 方向：仿写 / 迁移 / 反写，改动点是 ___
```

这六行都写不出理由的，说明这份剧本你还没读透，回去再读一遍，别急着动笔。

---

## 七、什么时候劝用户放弃这份剧本

出现以下情况，直接说「这份不适合改」，而不是硬改：

1. **结构依赖原片身份**：原片的说服力来自「我做了十年这行」，你没有这个身份
2. **事实无法替换**：核心证据是一个你拿不到的数据或案例
3. **原片本身就是改编**：再改一层，版权链条说不清
4. **只剩开头能借**：说明这份剧本对你没有结构价值，只借开头不如自己写

放弃一份剧本不丢人，改出一份四不像才是浪费。

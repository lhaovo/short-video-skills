# 五阶段作业规格

配合 SKILL.md 使用。每段都按同一套结构写：**进来要有什么、做什么、出什么、什么算过关、交接什么、容易卡在哪。**

---

## S1 · 剧本分镜

### 进来要有什么

| 项 | 没有怎么办 |
|---|---|
| 平台 | 必须问，不猜 |
| 目标时长 | 必须问 |
| 一句话方向 或 已有拆解剧本 | 两者都没有，先聊方向，别建目录 |

### 做什么

调用 `short-video-plan` 走它的流程（选题 / 判定 → 结构 → 剧本 → 分镜 → 自检）。本技能不介入内容判断。

### 出什么

`01-策划案.md`，五节，并在状态文件中记录项目验收画像；剧本打磨完成时，还要在当前回复中直接呈现一份可审阅剧本，方便用户确认和提出修改：

1. 主题简报
2. 类型与结构说明
3. 剧本（分段 + 钩子三问复核）
4. 分镜表（镜号 / 数值时长 / 内容 / 口播 / 屏幕文字 / 本镜功能）及按镜号对应的详情块（观众认知 / 前置依赖 / 关键可见事实 / 时长意图）
5. 自检结果（八问）

对话中呈现的剧本至少包含主题命题、分段任务、逐段口播、屏幕文字和待确认修改点；对话版本与落盘文件必须一致。

入口②（已有剧本）额外带一节「改写判定」，含复刻需求、复刻强度与改动点。

### 什么算过关（G1）

| 检查 | 判据 |
|---|---|
| 结构完整 | 五节齐全，无「待补」 |
| 自检八问 | 全过，含红线自查、台词可念性和节奏意图 |
| 总时长 | 与目标偏差 ≤30% |
| 单镜 | 每镜 2–6 秒，镜号连续 |
| 用户确认 | 选题与剧本都点过头 |
| 验收画像 | 内容类型、目标、节奏意图、最长无台词区间上限、静默承载方式、硬约束及验收人已记录；未确认的必需项记阻塞，缺上限不自设全局默认 |
| 分镜交接字段 | 每镜写明功能、观众认知、前置依赖、关键可见事实和时长意图 |
| 机械检查 | 策划技能可用时运行其 scripts/check_plan.py，逐镜字段、时长与依赖编号无错误；否则逐镜人工核对并记录 |

**没过就别进 S2。** 分镜表错了，后面每一段都会跟着错一遍。

### 交接卡（S1 → S2）

```
分镜表：镜号 / 数值时长 / 内容 / 口播 / 字幕 / 本镜功能；逐镜详情：观众认知 / 前置依赖 / 关键可见事实 / 时长意图
产品：真名、型号、必须准确的参数
必须真实呈现：包装、logo、规格数字、使用方式
不可出现：用户给的红线词
```

### 容易卡在哪

- 只有一篇散文稿，没有分镜表 → 先切分镜，别直接当生成清单用
- 口播字数与镜长算不平 → 以镜长为最终依据，改口播，不改时长表
- 镜号重排过，但下游还在用旧编号 → 交接卡一律重发一份完整表

## S2 · 提示词

### 进来要有什么

`01-策划案.md` 里的分镜表，且 G1 已过。

### 做什么

**作业法不在本技能内。** 本段调用 `short-video-prompt`，由它完成画面化、提资产、切段、组词、首帧与自检。

本技能在这一段只做三件事：

1. 把 `01-策划案.md` 交给它，并告知画幅、目标时长、**台词需原样写进提示词**
2. 收下它产出的 `02-资产清单.md`、`03-生成清单.md`
3. 按下面的 G2 逐条核，核过才放行到 S3

**加粗那一句是这次新增的。** 旁白不再独立配音，台词必须在 S2 就落进提示词。如果这一步漏了，S3 生成出来就是无声片段，得整段重来。

### 出什么

**`02-资产清单.md`** —— 这次制作要准备哪些图，谁复用谁：

| 编号 | 类型 | 用途 | 来源 | 被哪些段引用 | 状态 |
|---|---|---|---|---|---|
| PR-01 | 产品主体 | 一致性母版 | 真实拍摄 | S01、S02 | 已有 |
| SC-01 | 场景 | 环境 | AI 生成 | S01、S03 | 待出图 |

**`03-生成清单.md`** —— 每段一条，可直接执行：

| 段号 | 镜号 | 时长 | 模式 | 引用素材 | 首帧 | 后期项 | 候选数 | 前置依赖/关键事实 |
|---|---|---|---:|---|---|---|---:|---|

### 什么算过关（G2）

| 检查 | 判据 |
|---|---|
| 一一对应 | 每条提示词都有镜号，没有多出来的段 |
| 时长闭合 | 各段合计与分镜总时长差 ≤1 秒 |
| 引用不悬空 | 清单里出现的资产编号都在资产清单里有定义 |
| 模式唯一 | 首尾帧 或 参考图，二选一；文生仅用于无主体镜头 |
| 真图兜底 | 参数、包装、logo 镜头标明「必须用真实图」 |
| **台词在位** | 有台词的段都有旁白区块，且与分镜口播逐字一致 |
| 画面字段 | 每段有结构化“画面字段”表，写明主体、状态、动作、环境、光线、景别、机位/角度、运镜和依赖/可见事实；不适用项有原因 |
| 依赖传递 | 分镜关键可见事实和前置依赖已映射至首帧或段内动作 |

### 交接卡（S2 → S3）

```
任务：段号 + 时长 + 模式 + 参考图编号 + 提示词 + 候选数
台词：每段原文是否已写入提示词（逐字一致）
资产：每张图的状态（已有 / 待生成 / 待拍摄）
工具：用哪个模型、什么分辨率、什么画幅、音频必须开
顺序：先出资产图，再出首帧，最后出片段
```

### 容易卡在哪

- 资产没编号，同一只产品在清单里出现三种叫法 → 先统一编号
- 一段 12 秒还想一次生成 → 切成两段，写清交接帧
- 想同时用首帧和参考图 → 模型侧互斥，选一个

## S3 · 生成

### 进来要有什么

`02-资产清单.md`、`03-生成清单.md`，且 G2 已过。

### 做什么

S3 分两小段，**先图后片**：

```
3a 资产准备（交给 short-video-assets）
   资产图 → 首帧，按编号落盘，过验收
3b 片段生成（交给 short-video-generate）
   按生成清单建任务，逐段出 2–4 个候选，过媒体体检 + 抽帧质检
```

顺序不能倒。没有资产图就直接生成片段，第 3 段开始主体就会变样。

本技能在这一段只做两件事：把清单交给资产层、按 G3 收素材。**资产怎么出、片段怎么跑、怎么验，都不在这里写。**

### 出什么

```
04-素材/
├── 00-工单.md          资产生产工单（assets 层写）
├── 00-生成台账.md      片段任务与状态（generate 层写）
├── 01-资产图/    PR-01_产品主图_v1.png
├── 02-首帧/      S01_f01_v1.jpg
└── 03-片段/      S01_v1.mp4、S01_v2.mp4
```

命名规则：

| 类型 | 格式 | 谁负责 |
|---|---|---|
| 资产图 | `<编号>_<用途>_v<N>.<ext>` | `short-video-assets` |
| 首帧 | `S<段号两位>_f01_v<N>.jpg` | `short-video-assets` |
| 片段 | `S<段号两位>_v<N>.mp4` | `short-video-generate` |

**永不覆盖旧版本。** 选错了还能退回去。

### 什么算过关（G3）

| 检查 | 判据 |
|---|---|
| 齐 | 每段都有可用版本，缺的写进阻塞项 |
| 检 | 每段都过了媒体体检（文件、时长、比例、音轨符合提交参数） |
| 像 | 产品不变形、标签可读不改字 |
| 接 | 相邻段同一产品、同一光线方向、同一画幅 |
| 定 | 多候选时已选定并写进清单 |
| 角色识别点 | 对照策划案 IP/角色特征清单，逐镜核对标志性特征及数量 |
| 跨段因果与道具 | 用项目清单逐项核对前提出现顺序、指认对象是否在场、道具形制及归属；案例脚本中的固定镜号与颜色阈值不可直接移植 |
| 台词定案 | 听核定版片段并记录在 04-素材/00-台词定案.json；含糊处可用多次转写辅助，但须人工终审 |
| 全片 | 已按时间顺序人工审看定版片段，跨段因果、角色/道具状态、空间和节奏均有结论；问题已退回或记录为接受 |
| 节奏预检 | S3 用定版片段的台词时间轴或临时字幕预检；尚无成片字幕时记录「待 S4 实测」，不虚报已测 |
| 后期计划 | 生成清单承诺的拟音/叠字等后期项均有 S4 执行计划，无悬空承诺 |

「像」和「接」是抽帧看出来的，「检」是脚本跑出来的。两个都过才能算通过——**下载完成不等于可用**。

生成前审首帧故事板，确认空间、角色、证据和状态是否铺设；生成后仍须按时间顺序审看全片素材，确认动作、声音和跨段节奏。首帧故事板不替代动态审片。

### 交接卡（S3 → S4）

```
素材清单：定版映射文件 / 段号 / 实际时长 / 是否可用
缺口：哪段没有可用版本，什么原因
台词：每段是否已逐句听核，有无漏句或念错
全片审看：结论 / 跨段问题 / 是否退回
后期项：已完成 / 待完成 / 豁免及确认人
声音：BGM 是否已选
```

### 容易卡在哪

- 一段抽十几次都不对 → 问题多半在首帧或参考图，不在提示词
- 产品变形反复出现 → 该镜改成真实图打底 + 局部生成
- 段与段之间色调不一致 → 补一条统一的风格锚，重抽受影响段
- 同一段被提交了两次 → 没读台账，先查状态再动手，重复提交会拿到两个版本
- 台词总是漏后半句 → 字数超了，砍到 40 字以内或拆段

## S4 · 交付

### 进来要有什么

`04-素材/` 齐，每段台词已听核过，BGM 已选，且 G3 已过。

**没有配音环节。** 旁白已经在 S3 由模型念好，S4 只需要处理它。

### 做什么

按顺序五步，每步单独过一遍：

1. **粗剪对位** —— 按段号与镜号顺序拼，先不管节奏
2. **节奏修剪** —— 掐掉每段尾巴的废帧，切点落在动作完成处
3. **字幕** —— 以实际听到的台词为准逐句上，不按语音识别硬对齐
4. **混音** —— 人声打底，BGM 压到不盖字
5. **导出** —— 按平台规格导出，命名带版本

### 出什么

```
05-成片/
├── 成片-v1.mp4
└── 封面-v1.jpg
```

### 什么算过关（G4）

| 检查 | 判据 |
|---|---|
| 时长 | 与目标偏差 ≤10% |
| 字幕 | **与实际听到的台词逐句一致**，无错字、无错行 |
| 声音 | 人声清楚，BGM 不压人声 |
| 规格 | 画幅、分辨率、帧率符合目标平台 |
| 节奏对账 | 最长无台词区间符合验收画像；允许长静默的区间有分镜承载说明和交付定位 |
| 节奏实测 | 运行本技能 scripts/check_rhythm.py --srt <成片字幕.srt> --dur <成片秒数>，把报告及听核判断附在 00-流程状态.md；字幕空档只是无台词代理指标 |
| 后期闭环 | 生成清单承诺的后期项均已完成并引用产物，或有验收人确认的豁免 |

### 交接卡（S4 → S5）

```
成片：文件名、实际时长、画幅
封面：文件或待做
卖点：这一条最想让人记住的一句
素材授权：哪些画面涉及他人肖像或场地
```

### 容易卡在哪

- 分段生成的东西拼起来节奏碎 → 别用转场掩盖，重切尾巴
- 字幕跟着语音识别跑 → 以听核后的定版音轨为准，策划案口播和识别结果用于核对
- 导出后发现画幅不对 → 剪辑序列一开始就按目标平台设

## S5 · 发布

### 进来要有什么

`05-成片/` 的成片，且 G4 已过。

### 做什么

填 `06-发布包.md`，六件套：标题、封面文案、正文、话题、发布时间、AI 标识。规范见 `delivery-and-publish.md`。

### 出什么

`06-发布包.md`（模板见 `assets/publish-pack-template.md`）。

### 什么算过关（G5）

| 检查 | 判据 |
|---|---|
| 合规 | 强监管类目已另行审核，无绝对化用语、无未证实功效 |
| 标识 | AI 生成内容按平台要求标注 |
| 齐备 | 标题、封面、话题、时间都有 |
| 干净 | 无个人信息、无未授权肖像与场地 |

### 收尾

G5 过后：

1. 状态文件当前阶段改「已完成」，五门全填「过」
2. 版本记录加一行：日期 + 发布 + 平台链接或备注
3. 保留 `04-素材/` 不删——数据不好时要回来换段

## 附 · 全流程易错点

| 现象 | 真实原因 | 处理 |
|---|---|---|
| 越做越乱，找不到文件 | 没有按编号命名 | 回 S3 重命名，补清单 |
| 每段都好看，合起来不像一条 | 缺资产母版 | 回 S2 补资产，重出首帧 |
| 改一句台词要重做全片 | 提示词里写死了台词 | 台词走音频线，画面提示词不含台词 |
| 返工三轮还在原地 | 门没过就往下走 | 退回上一道门，逐条核 |

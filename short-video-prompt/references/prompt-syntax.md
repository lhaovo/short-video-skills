# 视频提示词语法

写每一条提示词时对照这份文件。核心只有一句：**把话说成画得出来的样子。**

---

## 一、六区块（唯一结构）

按顺序写，可删减，不乱序：

| # | 区块 | 写什么 | 缺了会怎样 |
|---|---|---|---|
| 1 | 风格 · 画幅 · 基调 | 时长、画幅、写实/动画、连续长镜或硬切、情绪基调 | 模型自主决定画幅与质感 |
| 2 | 素材引用 | `@图片1` 负责什么，`@图片2` 负责什么 | 素材被含糊地当成「整体参考」 |
| 3 | 锁定主体与场景 | 主体 anchor、场景布局、哪些必须不变 | 每段主体漂移 |
| 4 | 时间轴 | `0–3s:` 做什么，`3–6s:` 做什么 | 动作分配失控 |
| 5 | **台词 · 声音** | 说话人、台词原文（照稿念，一字不改）、环境音、动作音、有无配乐 | 模型串角色或自己编台词，字幕全废 |
| 6 | 质量与约束 | 结构稳定、无变形、无闪烁 | 畸形率上升 |

**第 5 区块是这套流程里最容易写错的一块。** 人物对白或旁白不再走独立配音，就靠这一段交给模型。四个要素缺一不可：说话人、台词原文、「照此念不改字」的约束、有无配乐。

### 完整示例

```
[风格画幅] 9:16 竖屏，8 秒，写实产品广告质感，硬切单镜，冷调晨光。

[素材引用] @图片1 锁定产品外观（白色双层不锈钢杯身、银色杯盖、侧面纵向 logo）；
@图片2 仅锁定场景（浅木色办公桌面）。不要继承图片背景与拍摄角度。

[锁定主体] 白色双层不锈钢随行杯立于桌面右侧，杯身在画面中占约三分之一。
场景：浅木色桌面，左侧键盘边缘入画，右后方模糊绿植。杯身朝向保持左前 45 度不变。

[时间轴] 0–4s：固定机位，镜头极缓推近，热气从杯口升起，在冷光里呈细白丝。
4–8s：一只手从右侧入画，指尖轻触杯盖，杯身轻微下沉再回弹。
Motion: steam rises slowly, fingers press the lid gently, the cup sinks then settles.

[台词·声音] 说话人：女主角。照此念，一字不改：「早上八点的咖啡，十点就凉了。」
声音：无配乐；环境音只保留办公室低频底噪，不盖人声。画面内无文字。

[质量] 杯身几何结构稳定，logo 清晰不变形，无闪烁无重影，构图稳定。
No subtitles.
```

差别不在形容词多，在**每一项都能被画出来**。

台词区块的两条纪律：

- **照抄结构化分镜的 `dialogue`，保留说话人，一个字都不改。** 改了字幕就对不上音，返工从 S1B 开始
- **不写语气标注、括号补充、重叠说话。** 模型不认这些符号，会原样念出来；多人连续对白按反应镜头拆段

## 二、短段的压缩写法

**只有无台词的空镜才能压缩。** 8 秒以内、单动作、不说话时，六区块可以压成一段话，顺序不变：

```
主体(anchor) + 动作 + 场景 + 镜头语言 + 光线 + 风格 + 质量约束
```

> 白色双层不锈钢随行杯，放在浅木色办公桌右侧，热气从杯口升起。固定机位缓慢推近。冷调晨光从左窗进入，在杯身形成一道窄高光。写实产品广告质感。结构稳定，logo 不变形，无闪烁。环境音只有办公室低频空调声，无对白。No subtitles.

**有台词的段落一律不能压缩。** 台词必须单独成段、先写说话人、再用引号包起来；混在散文里模型会当成描述而不是要念的话。

**超过 10 秒、或有两个以上动作、或需要挂素材引用时，也必须回到六区块。** 压缩写法一长就会丢约束。

## 三、镜头词表

### 运动（每段只选一种）

| 中文 | 英文 | 备注 |
|---|---|---|
| 固定机位 | static | 最稳，产品镜头优先 |
| 缓慢推近 | slow push-in | 最常用，制造注意 |
| 缓慢拉远 | pull-back | 收尾、揭示环境 |
| 左右摇 | pan left / right | 展示横向排列 |
| 上下摇 | tilt up / down | 揭示高度、体量 |
| 平行跟拍 | tracking alongside | 走路、移动 |
| 环绕 | orbit | 展示立体，慎用于产品（易变形） |
| 升降 | crane up / down | 大场面 |
| 手持跟随 | handheld follow | 带轻微晃动，真实感 |
| 轨道推拉 | dolly in / out | 与推近近似，位移更明显 |

**一条提示词里出现两种运动，必翻车。**「先推再摇」模型会自己融合成一个怪动作。

### 景别

大远景 → 远景 → 全景 → 中景 → 中近景 → 特写 → 大特写；另有：过肩、主观视角（POV）、航拍、插入镜头。

产品短视频里最常用三个：**中景（交代使用场景）、特写（讲细节）、大特写（讲材质与参数）**。

### 机位角度

平视（中性）、低角度仰拍（有压迫感/显大）、高角度俯拍（显小/看全貌）、鸟瞰、荷兰角（不安）。

### 速度词

slow / smooth / gradual / sudden / brisk / real time / slow motion。写「缓慢」就够，堆三个速度词模型无法执行。

## 四、Motion 清单（最高杠杆的一条）

在时间轴后显式写 `Motion:`，列出**什么在动、怎么动**。这是控制画面最有效的手段。

| 对象 | 可用词 |
|---|---|
| 人物 | subtle handheld drift, hair shifts, fingers fidget, micro pose adjust, breathes gently |
| 环境 | steam rises, fabric sways, dust motes drift, wind in branches, rain on glass |
| 产品 | lid opens smoothly, liquid pours, surface catches a highlight, label peels slightly |

**不写 Motion，模型会自己发明运镜**（常见是突兀的 zoom）。小幅动作比大幅动作可信。

一条 Motion 写 2–4 项就够。写十项等于没有重点。

---

## 五、时间轴

### 写法

```
0–3s：<景别/机位/运动> <可见动作与反应>。声音：<变化>
3–6s：<下一动作，承接上段结果>。声音：<变化>
```

三条硬要求：

1. **时间连续、不重叠、不留空档**：0–3 / 3–6 / 6–8
2. 每段只承载**一个主动作**
3. 后一段必须**承接前一段的结果**，不是重新开始

### 两种模式，不能混

| 模式 | 特征 | 禁忌 |
|---|---|---|
| 连续长镜头 | 全程不剪切，视角变化只由摄影机运动产生 | 时间轴里不能出现「切到」 |
| 分段剪辑 | 先声明剪辑节奏，再逐段标时间与景别 | 不能一边要求一镜到底一边写硬切 |

短视频里 **90% 是分段剪辑**：每段独立生成，剪辑台上拼。长镜头只适合展示类、氛围类内容。

## 六、素材引用要分配职责

有参考图时，必须说清**每张图负责什么**，以及**不继承什么**。

```
@图片1 锁定产品身份与外观；@图片2 仅锁定场景光线氛围；
不要继承图片背景、拍摄角度与姿势。其余以文字描述为准。
```

| 素材 | 可以绑定 | 不能含糊成 |
|---|---|---|
| 图片 | 身份、服装、产品外观、首帧构图、场景、文字样式 | 「参考这张图」 |
| 视频 | 动作编排、运镜、剪辑节奏、表演 | 「照这个感觉」 |
| 音频 | 配乐、节奏点、音色、音效 | 「配个类似的」 |

多条素材冲突时，写明以哪一项为准：**「产品外观以 @图片1 为准，场景以文字为准」**。

素材数量与格式限制随模型版本变化，**以当前生成界面的实际显示为准**，不要凭记忆写死数值。

## 七、质量与防变形约束（正向）

固定在末尾追加一小段：

```
主体几何结构稳定，边缘清晰，材质细节可辨，构图稳定，无闪烁、无重影、无变形。
```

分辨率**不写进提示词**，由提交参数决定（默认 480p）。写「4K」「1080p」不会让它真的变清晰，只会显得像关键词堆。

产品镜头加：

```
包装印刷清晰可读，logo 字形不变，标签无错字。
```

这些是**正向描述**（「结构稳定」），不是负向清单——原因见下一节。

---

## 八、视频与图像：负向词的分界线

**这是本技能里最容易搬错的一条。**

| | 视频提示词（Seedance 等） | 图像提示词（image-gen） |
|---|---|---|
| 负向词 | **基本不用**。写「no blurry hands」不按预期生效 | **大量使用**。资产图禁忌、面部铁律都是负向段 |
| 正确做法 | 描述**想要的样子**：「手指关节清晰，五指完整」 | 负向段整段粘贴：「no freckles, no studio strobe...」 |
| 例外 | 只留极少量结构性约束：`no deformation / no flicker / stable framing` | 无 |

所以：**视频侧靠正向描述，图像侧靠负向清单。** 把资产图那一大段 negative 粘进视频提示词，不但无效，还会稀释前面的有效信息。

---

## 九、长度与信息密度

**五个信息密集的句子，胜过二十句模糊的话。**

- 单段提示词控制在一屏以内（约 120–200 字），超出就要检查是否塞了两个动作
- 每个词都要指向可见或可听的内容：「高级感」「有质感」「氛围好」全部删掉
- 同一件事不重复描述：主体描述在前，时间轴里不再重复外观

---

## 十、写的时候就要避开的七种写法

| 写法 | 为什么不行 |
|---|---|
| 抽象形容词堆叠（震撼、电影感、8K 大片） | 不指向任何可见内容 |
| 一条提示词塞三个场景 | 一个 prompt 只能是一个连续时刻 |
| 单段堆多个运动（推完摇再升降） | 模型会融合成怪动作 |
| anchor 用近义词替换 | 触发重新生成，一致性断裂 |
| 自相矛盾（高速运动 + 极致稳定） | 只能取其一 |
| 小说式长描述 | 字数越长，前面越被稀释 |
| 视频里塞长负向清单 | 无效，且挤掉有效信息 |

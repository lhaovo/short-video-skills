# 失败诊断

某一段反复生成不出来时查这份。**先按症状定位，再按顺序排查，不要一上来就改提示词。**

---

## 一、排查顺序（重要）

```
资产图 → 首帧 → 提示词 → 模型能力 → 该不该实拍
```

多数人从第三步开始改，改十版还是不对。原因很简单：

| 层次 | 决定了什么 | 出问题的表现 |
|---|---|---|
| 资产图 | 第 3 段以后还是不是同一个东西 | 每段都不一样、产品变形 |
| 首帧 | 这一段从哪里开始、构图对不对 | 构图总是错、主体位置乱 |
| 提示词 | 这一段好不好看、动作对不对 | 单段能看，但动作/光线不理 |

**判断方法**：如果同一条提示词，换 3 次结果「主体都不一样」，那不是提示词问题，往上找。

---

## 二、按症状查

| 症状 | 病根 | 改哪 |
|---|---|---|
| 产品/人物每段长得不同 | 缺资产母版，或 anchor 每段重写 | 补资产，anchor 逐字复制（`consistency.md`） |
| 产品变形、比例乱 | 用了大角度环绕运镜；或纯文生 | 换固定机位/小角度推近；产品镜头改首帧模式 |
| 高光过曝、金属发亮片 | 写了「镜面感」「高光」类词 | 改「哑光、低反光」，光位换成漫射 |
| 动作跳跃、物体瞬移 | 一段里塞了两个动作 | 拆段，一段一动作 |
| 动作僵硬、像定格 | 只写了末端姿势 | 写中途态 + `Motion:` 清单 |
| 长镜头被莫名剪辑 | 时间轴里出现「切到」「硬切」 | 删掉切换词，声明视角只由运镜产生 |
| 快速剪辑失去连贯 | 每段信息太多 | 一段只留一个重点，重复位置锚点 |
| 画面太静、主体不动 | 只写机位没写运动 | 补 `Motion:` 与镜头跟随方式 |
| 画面像摆拍、过于干净 | 缺可信瑕疵 | 加手持微晃、对焦轻搜、材质磨损（别全加） |
| 画面「发脏」、皮肤沸腾 | 人物图皮肤高频太密 | 回资产图，按人物负向段重出（`assets.md`） |
| 声音混乱 | 无对白与有台词并存 | 明确：有无对白、谁在说、语言、是否要环境音 |
| 物理不可信 | 只写「真实物理」 | 写重量、受力点、接触、二次反应 |
| 参考图没起作用 | 只说「参考这张图」 | 逐张分配职责，写明不继承什么 |
| 文字出现乱码 | 让模型在画面里写字 | 画面不写字，改后期字幕 |
| 时长不够用 | 一段塞了太多动作 | 切段，或改用交接帧延展 |

---

## 三、按环节查

### 画面化阶段

- 「这一镜讲什么」能否落实为主体/状态/动作/环境/光线/景别/机位角度/运镜八项？
- 拆不出来的，说明这句话本身没有画面，回上游改分镜

### 资产阶段

- 产品镜头有没有对应的素材？纯 AI 出的图有没有锁几何与印刷？有宣称的镜头用的是不是实拍或官方图？
- 同一产品有没有两个编号（PR-01 和 PR-01B 混用）？
- 场景图有没有「整体空间结构」，还是只有一堆物件？

### 切段阶段

- 每段是不是只有一个动作？
- 段长够不够念完这段台词（按 4 字/秒算），有没有单段超过 36 字？
- 换场景的地方切了没有？

### 组词阶段

- 六区块有没有缺项？最常见缺的是 `Motion:` 和 `No subtitles`
- 运镜是不是只有一种？
- 有没有把资产图的负向段误粘进视频提示词？

### 生成阶段

- 候选数够不够（建议 2–4）？
- 参数（分辨率、画幅、时长）是不是在模型支持范围内？
- 首帧与提示词描述是不是同一个构图？

---

## 四、什么时候该停止重抽

出现下面任一情况，说明方向错了，继续抽是浪费：

1. **同一段抽了 6 次以上，问题始终是同一类**（比如一直是产品变形）→ 换资产或换模式
2. **动作需要精确参数展示**（刻度、温度读数）→ 不该交给 AI
3. **需要证明功效**（保温六小时、防水）→ 生成画面证明不了任何事，只能实拍或做示意
4. **要出现可读的中文** → 交给后期

这四种情况不是提示词能解决的。**该换路子就换路子，不要让技能假装能解决。**

---

## 五、一句判断规则

**提示词决定单段好不好看，资产决定几段能不能接。**

如果片子「每段单独看都行，合起来不像一条」，别改提示词，回资产。
如果片子「接得上但每段都不好看」，才是提示词的事。

# 视频提示词怎么写

核心一句：**提示词只描述"变化"，不描述"是什么"。**

首帧图已经把产品长什么样交给模型了。提示词再描述一遍产品，等于让它按文字重画一次——两次描述必然不一致，主体就变了。

## 一、七段结构

按顺序写，一段一句或两短句，总共控制在一屏以内。

```
① 首帧锁定：保留什么，不许重绘什么
② 主动作：一个连续、可观察的动作
③ 环境动作：最多一个低干扰变化
④ 运镜：一种稳定运镜，或固定机位
⑤ 节奏：从第几秒开始、怎么收
⑥ 旁白台词：照稿念，一字不改（第七段规则见下）
⑦ 限制：无字幕、无新增文字、无额外人物、无闪烁
```

### 示例（首帧模式，6 秒）

```
保持首帧里的杯子形状、颜色、标签位置和桌面构图不变，不重绘任何文字。
一只手从右侧入画，握住杯身中段缓慢抬起，动作连续不中断。
杯口的热气随动作轻微飘动。
镜头固定，不做推拉。
动作从第 1 秒开始，第 5 秒停稳，最后 1 秒保持静止。
旁白（照此念，不改字）：「早上八点的咖啡，十点就凉了。」
声音：无配乐，环境音只保留办公室低频底噪，不盖人声。
画面无字幕、无新增文字、无额外人物、无闪烁、无变形。
```

### 示例（文生模式，5 秒，空镜）

空镜没有台词，就不写旁白段，只写声音。

```
浅木色办公桌面，左侧窗光斜射，晨间薄尘在光柱里浮动。
一杯白色随行杯静置在桌角，杯口有缕热气缓缓升起。
窗帘极轻微摆动。
镜头缓慢横移约 5%，速度均匀，全程不切换。
写实商业质感，暖调，浅景深。
声音：只有室内轻微底噪，无对白，无配乐。
画面无字幕、无新增文字、无人物、无闪烁。
```

### 示例（首尾帧模式，8 秒）

```
从首帧的合盖状态出发，保持杯子外观、桌面和光线方向不变。
手握杯盖逆时针拧开，抬起杯盖，露出杯口。
热气从杯口升起，逐渐变淡。
镜头固定。
动作在第 1 到 6 秒完成，第 6 到 8 秒保持末帧的静止状态。
旁白（照此念，不改字）：「拧开这一步，决定了它能不能撑到下午。」
声音：拧盖的短促摩擦声，无配乐，不盖人声。
口型：说话人不在画面内，用画外音。
画面无字幕、无新增文字、无额外人物、无闪烁、无跳切。
```

## 二、五条硬规矩

1. **一镜一个主动作。** 出现「先……再……最后」就是多段剧情，模型会自己跳剪。
2. **台词照抄稿子，一个字不改。** 旁白不再走独立配音，改由模型直接念，所以每段的台词原文必须写进提示词。**改动一个字，字幕就对不上音。**
3. **不让模型写文字。** 字幕、数字、参数、logo 一律后期。要模型"写"中文必错——但"念"中文是可以的，这是两件不同的事。
4. **运镜只写一种。** 「推近 + 横移 + 旋转」= 模型全做得很差。要么固定，要么一种。
5. **不堆否定句。** 末尾三到五条限制够了，几十条互相冲突的"不要"会让模型无所适从。

### 第七段：台词与声音

六段结构之后必须多一段，写法固定：

```
旁白（照此念，不改字）：「这一段的口播原文，一字不改贴进来。」
声音：无配乐；环境音只保留低频底噪，不盖人声。
口型：说话人若在画面内，口型与旁白同步；若不在画面内，用画外音。
```

三件事按顺序写，缺一不可：

| 要素 | 为什么必须写 | 漏了会怎样 |
|---|---|---|
| 台词原文 | 模型按它发音、按它定时长 | 它会自己编一段，字幕全废 |
| 「不改字」 | 明确约束，减少自由发挥 | 擅自改写、增删词 |
| 有无配乐 | 决定后面要不要压掉 | 音乐盖过人声，只能重新生成 |

### 台词文本怎么写得让模型念得准

| 做法 | 原因 |
|---|---|
| 一句一个意思，**每句不超过 15 字** | 长句断句必乱 |
| 用常用字，避开生僻字、多音字 | 生僻字大概率念错 |
| 数字写成汉字（「六小时」不写「6h」） | 符号它不知道怎么念 |
| 品牌名单独成句，前后加停顿 | 夹在长句里会被吞掉 |
| 不写语气标注（[兴奋地]）（笑） | 它不认，会念出来 |
| 不写重叠说话、括号补充 | 会变成含糊的杂音 |

### 仍然不要交给模型的内容

**准确到字的品牌名、型号、参数，即使写在台词里，也要有心理准备念不准。**

这时有两条路：

1. 这一段台词改由后期补录，画面用 `--no-audio` 重出（干净，但要重跑）
2. 接受模型念的版本，但**字幕按实际听到的改**，不要照原稿打

**不要选第三条**：念错了却按原稿上字幕。观众听到的和看到的对不上，比念错本身更伤。

## 三、长度怎么控制

按模型念中文约 **4–5 字/秒** 估，宁可少写不要写满：

| 段时长 | 提示词量 | 动作数 | 台词量 |
|---|---|---|---|
| 4–5s | 3–4 句 | 1 个 | ≤ 22 字 |
| 6–8s | 4–6 句 | 1 个 + 1 个环境变化 | 25–36 字 |
| 9–12s | 6–8 句 | 1 个主 + 1 个次，且中间要有停顿 | 40–54 字 |
| 13–15s | 不推荐 | 超过 12 秒的镜头，观众会走 | 不推荐超过 60 字 |

**台词量比动作量更容易超。** 模型不会为了塞下你的台词而加快语速到失真，它更可能直接漏念半句。所以宁可少写几个字。

表里给的是"还能念完"的上限，不是"应该写满"。**一段 20 个字、留有呼吸，比塞 36 个字念得急好听得多。**

**长镜头不等于给模型更多词。** 给它更多词它只会塞进更多动作，结果是又乱又快。

## 四、衔接怎么保证

相邻两段能接上，靠四件事，不是靠提示词写得像：

1. **同一张母版图** —— 两段的首帧都从同一个资产派生
2. **同一句风格锚** —— 光线方向、色温、景深那句话逐字复用，不要换说法
3. **末帧与下一段首帧对齐** —— 要么用首尾帧模式显式指定，要么在提示词里写清"结尾保持静止，主体位于画面中部偏左"
4. **声音基调一致** —— 声音那一句照抄上一段，只把动作音换成这一段的

第三条最容易漏。第 2 段一开始主体跑到了右边，第 3 段从左边开始，剪一起就是跳。

**第四条现在同样重要。** 每段由模型独立生成，声音也独立。一段是室内底噪、一段突然变成街道嘈杂，或者一段有很响的配乐、一段完全干声，拼起来就有断裂感。统一写法：

```
声音：无配乐，环境音只用办公室低频底噪，不盖人声。
```

这句逐段照抄，只改动作音那半句。

## 五、什么镜头别硬跑

| 镜头类型 | 为什么 | 怎么办 |
|---|---|---|
| 参数特写、刻度、包装文字 | 模型必写错字，且构成虚假宣传 | 后期贴图，或实拍 |
| 功效演示（保温六小时、不洒） | 模型证明不了任何事 | 实拍，或改为示意图 |
| 真人正面信任镜头 | AI 脸在转化环节是减分项 | 实拍，或用数字人 |
| 多步骤操作演示 | 步骤必然错乱 | 拆成多个短镜，或后期图示 |
| 屏幕上滚动的 UI | 必然成为乱码 | 后期绿幕合成 |
| **一段里超过 36 字的台词** | 模型念不满就会漏句或赶 | 拆成两段，或删字 |
| **必须念准的品牌名 + 型号** | 大概率念错 | 拆出去走后期补录 |

这几类镜头硬跑，大概率是抽十几次都不对，最后还是要回到后期。

## 六、改提示词的顺序

不要一次改三处。按这个顺序，一次一处：

1. **先确认首帧对不对**（不对就换图，改词没用）
2. 再确认台词有没有漏字、错字（一个字不对，字幕就错位）
3. 再删动作（动作越少越稳）
4. 再改运镜（固定机位最稳）
5. 最后改措辞

大多数"提示词写不好"的问题，实际坏在第 1 步。第 2 步是这次新增的——台词进提示词之后，**一处改动就会牵到字幕**，所以要比动作更早检查。

# 片段质检与返修

下载完成不等于可用。这里分两层：脚本判客观参数，人判画面质量。

## 一、第一层：媒体体检（脚本）

```bash
python scripts/inspect_clip.py --file 04-素材/03-片段/S01_v1.mp4 --ratio 9:16 --duration 6
```

| 查什么 | 判据 | 不过怎么办 |
|---|---|---|
| 文件存在 | — | 重新下载同一 taskId |
| 大小 | 非空 | 同上 |
| 时长 | 与预期差 ≤0.5s | 参数或模型问题，重出 |
| 比例 | 与预期一致（容差 2%） | **判失败**，不许裁黑边糊过去 |
| 音轨 | 带台词的段必须有（`--expect-audio`）；纯空镜应为无（`--no-expect-audio`） | 该有却没有 → 检查是否误用 `--no-audio`，重出；不该有却有 → 后期静音即可 |
| 分辨率 | ≥640 短边 | 低于则提示可能是 480p 出错了 |

退出码 `0` 通过 / `2` 有问题 / `3` 环境缺失（没装 ffprobe）。

**音轨这一项只能判"在不在"，判不了"里面是什么"。** 有没有多余人声、念错名字、音量爆掉，只能自己听一遍，见第三节。

## 二、第二层：抽帧质检（人）

抽**至少三个点**：第 1 秒、中点、最后一帧。用 ffmpeg 抽：

```bash
ffmpeg -y -ss 0.5 -i S01_v1.mp4 -frames:v 1 S01_p1.jpg
ffmpeg -y -ss 3   -i S01_v1.mp4 -frames:v 1 S01_p2.jpg
ffmpeg -y -sseof -0.5 -i S01_v1.mp4 -frames:v 1 S01_p3.jpg
```

七项逐条看：

| # | 项 | 看什么 | 致命 |
|---|---|---|:---:|
| 1 | 主体一致 | 与资产图/首帧相比，形状、颜色、标签有没有变 | ✓ |
| 2 | 无新增物 | 有没有多出的人、手、物品 | ✓ |
| 3 | 无文字重绘 | 画面上有没有冒出乱码文字、假 logo | ✓ |
| 4 | 无畸形 | 手指数量、边缘断裂、结构错乱 | ✓ |
| 5 | 无闪烁 | 三帧之间亮度/色温有没有跳 | ✓ |
| 6 | 运镜符合 | 是不是只有一种稳定运动 | |
| 7 | 首尾可接 | 末帧能不能与下一段首帧接上 | ✓ |

1–5 任意一条不过 = **质量失败**，直接重做，不要凑合。
6 不过 = 告警，能接受就用。
7 不过 = 要看下一段是否已有可用版本，否则改首尾帧模式重出。

## 三、第三层：核台词（人，必做）

先从定版片段抽取音轨，逐句听核；对含糊的关键字、品牌名或数字，允许用同一音频重复转写至少三次作辅助证据。多数结果仍须人工听核；三次结果分散或与耳听不一致时，标为「未定」，返查音频或重出片段，不在字幕上猜。按 assets/dialogue-final-template.json 填写 04-素材/00-台词定案.json，记录段号、定版文件、原稿、转写结果、人工终审文本与结论，交 S4 做字幕；纯空镜标记「无台词」。转写结果不能单独替代耳听。

**人物对白与旁白由模型生成，所以每段带台词必须听着核。** 这一步不是"顺便听一下"，是判通过的必要条件。

对照原稿，核五项：

| # | 核什么 | 常见毛病 | 怎么处理 |
|---|---|---|---|
| 1 | 句数对不对 | 原稿三句，只听到两句 | **重出**（漏句无法后期补） |
| 2 | 有没有念错字 | 生僻字、多音字念成别的 | 换常用说法后重出 |
| 3 | 关键词对不对 | 品牌名、型号、数字含糊或错 | 重出，或改字幕贴合 |
| 4 | 有没有多余人声 | 模型自己加了一句含糊人话 | 重出，提示词里加「只用指定说话人与台词」 |
| 5 | 有没有被盖住 | 配乐或环境音盖过人声 | 补「无配乐，不盖人声」重出 |

**1 和 3 是硬伤。** 漏句意味着信息缺失，念错关键字在小红书、视频号这类会被逐字看的平台上是硬伤。

2、4、5 能后期修就不重出——重出一次的成本比修一次高得多。

### 念的和稿子不一致时，只有两条路

```
① 重出这一段（成本高，但字幕可以照原稿）
② 保留画面，把字幕改成实际听到的内容（成本低，但信息被动了）
```

**绝对不要选第三条：照原稿打字幕。** 观众听到的和看到的对不上，比念错本身更伤——尤其是带数字、带价格的段落。

### 一条相邻段的问题

每段独立生成，语速也会有差异。两段拼起来，可能出现一段偏快、一段偏慢。这不是错误，但**剪辑时要注意听过渡**，必要时对某段做轻微变速（±5% 以内听不出来）。

## 四、失败归因：先归类，再改

| 现象 | 病根 | 修法（按顺序试） |
|---|---|---|
| 主体变形、产品变样 | 首帧不对，或根本没首帧 | 换首帧 → 改首帧模式补齐 |
| 画面抖、闪烁 | 动作写多了 | 删到只剩一个动作 → 改固定机位 |
| 多出手指 / 手部错乱 | 要求了复杂手部动作 | 手部动作改成"入画""轻轻搭着" |
| 文字乱码、假 logo | 要求模型写文字 | 文字全交后期，提示词里明确"不重绘文字" |
| 比例不符 / 黑边 | 参数与返回不一致 | 判失败重出，**不裁黑边** |
| 动作太快、像快进 | 动作数量超了 | 减少动作，延长停留 |
| 段间跳色 | 光线描述不一致 | 统一风格锚那句话，重抽受影响段 |
| 段间位置跳 | 末帧与下一段首帧不接 | 用首尾帧模式，或补交接帧 |
| **漏念、只说半句** | 台词字数超出镜长 | 砍台词 → 拆成两段 |
| **念错字 / 念成近音词** | 生僻字、多音字 | 换成常用说法 → 换词重出 |
| **品牌名被吞掉** | 夹在长句中 | 让品牌名单独成句，前后留停顿 |
| **人声被配乐盖住** | 没写"无配乐" | 补声音约束重出 → 或后期压配乐 |
| **完全无声** | 误用 `--no-audio` | 检查参数，重出 |
| 反复失败十几遍 | 该镜本身不该交给模型 | 回 S4 后期方案，或改实拍 |

## 五、返修纪律

**一次只改一个变量。** 同时改提示词、时长、首帧，成功了你也不知道是哪个起作用，下次同样的坑还会踩。

推荐顺序（从最可能到最不可能）：

```
① 首帧对不对 → ② 台词字数 → ③ 动作数量 → ④ 运镜 → ⑤ 措辞
```

大多数"提示词写不好"的问题，第 ① 步就解决了。

第 ② 步是台词专用。**台词念不对时，先看字数，再看用字**——超长的段落，模型不会加快语速，它会直接漏掉后半句。砍到 36 字以内，问题往往就没了。

## 六、什么时候该停手

同一段连续返工达到下列触发点，先在台账写下根因假设（提示词/资产/分镜/模型/参数/检查器），下一轮只改一个变量并记录结果；不是机械禁止继续生成。

出现这些信号，先暂停盲抽并定位根因，再决定下一轮是否重出：

1. **同一段连续 3 个候选都过不了同一项** —— 检查是否是资产、镜头或参数设计问题
2. **提示词已经改到第 4 版** —— 回看这段是否更适合后期或实拍方案
3. **需要精确文字、精确步骤、精确参数** —— 优先考虑可控的后期呈现

返工方案可回 S4 使用贴图、字卡、实拍插入或合成；改动涉及叙事功能时同步回查 S1 分镜。

## 七、候选怎么挑

一段跑 2–4 条是正常成本，不是浪费。挑的时候按这个优先级：

```
主体稳定 > 无畸形 > 无文字错 > 运镜可控 > 动作好看
```

前两项不过直接淘汰，不用再比较第 3 项。挑中的那条写进台账，其余留在目录里（不删，方便对比）。

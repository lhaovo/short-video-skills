# S4 装配操作核对

按项目实际素材与编辑工具选择实现；以下是 FFmpeg/libass 方案容易踩的技术点，执行前用短样片验证。

| 环节 | 核对方法 |
|---|---|
| libass 字幕分辨率 | ASS 的 PlayResX/PlayResY 与目标画幅相符；从旧稿移植字号时按 target_h / PlayResY 检查实际视觉尺寸，再以预览调整。 |
| 音频交叉淡化 | acrossfade=d 输出时长通常为两段输入时长之和减去重叠的 d；核对切点与总时长，别直接相加。 |
| filter 输入流 | 同一输入若被两条滤镜链使用，先 split/asplit 得到独立流，再分别处理；每个标签检查只消费一次。 |
| Windows 路径 | 路径作为 filter 参数时，盘符冒号、反斜杠等须按 FFmpeg 滤镜语法转义；优先用相对路径或先转换路径并验证命令。 |

推荐按画面拼接、叠字、渐隐、混音、字幕逐步出预览并检查；实际顺序以画面叠层和声音要求决定。每一步核对输入来自定版映射，不从 _留档/ 自动选最新文件。
